# Phase 1 測試紀錄

測試日期：2026-10-31
環境：雲端容器、Node 22、headless Chromium（Playwright，WebGL 由 SwiftShader 軟體算繪）
腳本：`scripts/e2e-interactions.cjs`（開發模式，透過 `window.__hs` 設定玩家位置後點擊互動面板）

> 軟體算繪幀率很低，因此**沒有**測量真實裝置效能；實機（桌機、手機）流暢度仍需人工確認。
