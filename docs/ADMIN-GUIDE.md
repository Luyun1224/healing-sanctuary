# 管理員使用說明（Phase 3）

## 一、更新公開 API（必做）

Phase 3 在 `gas/Code.gs` 新增了主持人申請、主持人登入、集體靜心邀請與暱稱過濾。請更新已部署的 Apps Script：

1. 打開資料庫試算表 → 擴充功能 → Apps Script。
2. 用 repo 最新的 [`gas/Code.gs`](../gas/Code.gs) 全文取代後儲存。
3. 部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署。**網址不變**，網站不需重新設定。
4. 到 GitHub Actions 執行 *Check GAS multiplayer API*（人數 0）確認連線正常。

## 二、建立管理後台（獨立的 Apps Script 網頁應用程式）

管理後台與公開 API 分開部署，並且必須以 Google 帳號登入：

1. 到 <https://script.google.com> → 新增專案，命名「心靈充電所管理後台」。
2. 把 `Code.gs` 內容換成 [`gas/admin/Admin.gs`](../gas/admin/Admin.gs)。
3. 檔案 ＋ → HTML，命名為 **Admin**（不要加 .html），貼上 [`gas/admin/Admin.html`](../gas/admin/Admin.html)。
4. 專案設定（齒輪）→ 指令碼屬性，新增：
   - `SPREADSHEET_ID`：資料庫試算表網址中 `/d/` 與 `/edit` 之間那一串。
   - `ADMIN_EMAILS`：管理員的 Google 帳號，多位用逗號分隔，例如 `a@hospital.org,b@hospital.org`。
5. 部署 → 新增部署作業 → 網頁應用程式：
   - **執行身分：存取網頁應用程式的使用者**
   - **誰可以存取：擁有 Google 帳戶的任何使用者**（若機構使用 Google Workspace，建議選「機構內的所有人」）
6. 把資料庫試算表**共用給每位管理員（編輯者）**。後台以登入者本人的權限讀寫試算表，所以沒有編輯權的人即使拿到網址也無法修改任何資料；後台程式也會再比對 `ADMIN_EMAILS`。
7. 每位管理員第一次開啟後台網址時，需要同意 Google 授權。

> 安全重點：前端網站沒有任何管理員密碼；所有權限都在 Google 伺服器端確認。所有後台操作都會記錄在試算表的 `AdminLog` 工作表。

## 三、日常操作

| 工作 | 後台分頁 | 說明 |
| --- | --- | --- |
| 審核值日陪伴員 | 主持人申請 | 一般同事請核准為「值日陪伴員」。「虛擬住持／神父／牧師」等正式職稱需勾選「已確認具正式身分或授權」才能核准。 |
| 交付主持人金鑰 | 主持人申請 | 核准後畫面會顯示一次「主持人金鑰」，請私下交給本人（例如院內訊息）。系統只保存金鑰的雜湊，遺失只能重新申請核准。 |
| 停用主持人 | 主持人名單 | 停用後約 60 秒內金鑰失效。 |
| 發布每日一句 | 每日一句 | 選日期與場景（可選「全部場景」），內容最多 120 字。會顯示在右下角卡片、教堂祝福看板，主持人靠近同事時也會以對話泡泡分享。 |
| 發布公告 | 公告 | 可設定開始與結束時間（預設 7 天）。 |
| 移除不適當內容 | 每日一句／公告 | 按「移除」，狀態改為 removed（保留紀錄）。 |
| 過濾不適當暱稱 | 功能開關 | `blockedWords` 填入關鍵字（逗號分隔），含這些字的暱稱無法進入多人房間。 |
| 暫停多人功能 | 功能開關 | `multiplayerEnabled` 設為 false，所有人回到單人模式；`interactionsEnabled` 控制揮手與祝福泡泡。 |
| 管理房間 | 房間 | 調整人數上限、停用房間或新增房間（例如 `temple-2`）；第一個房間額滿時會自動進入同場景的下一個房間。 |

## 四、值日陪伴員怎麼使用

1. 在遊戲中按 🌿「療癒」→「申請成為值日陪伴員」，填暱稱、場景、日期與簡短自我介紹（不需真實姓名）。
2. 收到管理員給的金鑰後：🌿 →「主持人登入」貼上金鑰。名牌會出現「值日陪伴員」標籤。
3. 🌿 →「主持人工具」可發送 1／3／5 分鐘的集體靜心邀請（每 5 分鐘一次）。同房間的人會看到邀請卡，可以選擇「一起參加」或「這次先不用」，不會被強制切換畫面或音樂；開啟「專注靜心模式」的人不會收到。
4. 金鑰只存在該瀏覽器分頁，關閉分頁就會登出；共用電腦請記得關閉分頁。

值日陪伴員的工作是問候、鼓勵與陪伴，**不是心理治療或宗教諮詢**；遇到需要專業協助的同事，請轉介院內相關資源。
